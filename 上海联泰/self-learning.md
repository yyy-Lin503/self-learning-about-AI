## 1.2 从 RNN 到 Transformer：为什么大语言模型能破局？

**教学目标：** 从零理解 Transformer，具备向非技术人员解释的能力

- [ ] 能用自己的话说清大语言模型的本质：统计学的概率事件，在海量数据里学到统计规律
- [ ] 理解 Token 与词嵌入：文本如何变成数字
- [ ] 掌握注意力 QKV 公式：QKV 的含义、注意力分数计算、缩放点积
- [ ] 理解多头注意力：多组 QKV 并行的意义
- [ ] 理解前馈神经网络：每个 token 独立消化信息
- [ ] 理解位置编码：为什么需要 RoPE 等主流方案
- [ ] 能逐步推演完整数据流：从输入到输出
- [ ] **实操：** 手写一个极简版单头注意力（纯 Python）
- [ ] **实操：** 对照 Tensor Core 4×4 矩阵涂色图，理解底层运算

## 1.3 算力硬件全景：GPU / CPU / NPU / DPU

**教学目标：** 能根据业务场景选型，不被供应商忽悠

- [ ] 理解 CPU：通用计算的核心，擅长逻辑控制、分支密集任务
- [ ] 理解 GPU：大规模并行计算之王，训练与推理的主力
- [ ] 理解 NPU：专用 AI 加速器，端侧推理、能效比优势（高通 Hexagon、苹果 ANE、华为昇腾）
- [ ] 理解 DPU：数据处理器，卸载网络、存储、安全虚拟化（NVIDIA BlueField、Intel IPU）
- [ ] 能从算力密度、能效比、编程生态、部署成本四个维度做对比选型
- [ ] **实操：** 在服务器上使用 `lspci`、`nvidia-smi` 识别各计算单元
